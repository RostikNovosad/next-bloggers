# Persona — вітрина AI-блогерів

Тестове завдання: мобільно-орієнтована вітрина з чотирма AI-блогерами. Головна сторінка з історіями та картками блогерів і профіль кожного блогера з діалогом, публікаціями та переходом у Telegram. Весь інтерфейс українською.

## Що є на сайті

**Головна (`/`)**
- заголовок, історії блогерів (відкриваються на весь екран) і демо-чат на телефоні;
- картки чотирьох блогерів;
- блок «Як це працює» та заклик перейти в Telegram.

**Профіль (`/[id]`)**
- картка в стилі Instagram: фото, імʼя, нікнейм, статистика, теми, опис, кнопки «Перейти в Telegram» і «Написати»;
- карусель публікацій (стрілки на десктопі, свайп на телефоні) та модальне вікно публікації;
- чат-віджет: спливаюче привітання, а після відкриття діалог із швидкими відповідями;
- блок «Інші блогери».

## Технології

- Next.js 16 (App Router), React 19, TypeScript
- Tailwind CSS 4
- AOS для анімацій появи
- `next/image` для оптимізації зображень

## Запуск

```bash
npm install
npm run dev
```

Сайт відкриється на http://localhost:3000.

Щоб відкрити з телефона в тій самій Wi-Fi мережі:

```bash
npm run dev -- -H 0.0.0.0
```

і зайти на `http://<IP комп'ютера>:3000`. Адресу потрібно додати до `allowedDevOrigins` у `next.config.ts` (для діапазонів `192.168.0.*` і `192.168.1.*` уже додано).

Продакшн-збірка:

```bash
npm run build
npm start
```

## Структура

```
app/
  page.tsx           головна
  [id]/page.tsx      профіль блогера
  globals.css        кольори, кнопки, базові стилі
components/          Header, Footer, Stories, PhoneChat, ChatDemo,
                     ProfileView, PostCarousel, PostModal, PostTile, ...
lib/bloggers.ts      дані блогерів, публікації, діалоги, TELEGRAM_URL
public/
  images/            портрети та аватарки блогерів
  content/<імʼя>/    фото публікацій (1.jpeg - 4.jpeg)
```

## Як змінити контент

- **Блогери, тексти, діалоги, публікації:** `lib/bloggers.ts`.
- **Посилання на Telegram:** константа `TELEGRAM_URL` у `lib/bloggers.ts` (зараз `https://t.me/`, потрібно підставити реальне).
- **Фото публікацій:** файли у `public/content/<імʼя>/`, шлях задається полем `image` у публікації. Якщо кадр не 4:5, поле `imagePosition` керує обрізанням.
- **Портрет і аватарка:** поля `photo` та `avatar`. Поле `face` задає центр обличчя та масштаб для автоматичного кадрування на картках.
